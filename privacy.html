Privacy

This website

The bulkstem.com website collects nothing. It sets no cookies, runs no analytics and makes no requests to third parties: every file it loads comes from bulkstem.com.

The BulkStem application

BulkStem stores all data locally on your Mac, in the voyage files you save. No calculation, file or report depends on the network, and no data leaves your Mac. The only network use is checking for application updates, which you can trigger yourself.
